## Installation

```bash
npx shadcn@latest add @odiaui/button
```

## Usage

```tsx
import { RollingButton } from "@/components/ui/button"

export function Example() {
  return <RollingButton>Hover me</RollingButton>
}
```

## Stagger

Each letter starts its animation slightly after the previous one. Control the
gap with the `stagger` prop (in milliseconds).

```tsx
<RollingButton stagger={40}>Slow roll</RollingButton>
<RollingButton stagger={0}>All at once</RollingButton>
```

## API

| Prop       | Type                                          | Default     |
| ---------- | --------------------------------------------- | ----------- |
| `children` | `string`                                      | required    |
| `variant`  | `"default" \| "secondary" \| "outline" \| "ghost"` | `"default"` |
| `size`     | `"sm" \| "default" \| "lg"`                   | `"default"` |
| `stagger`  | `number`                                      | `20`        |

All native `<button>` props are supported. `children` must be a plain string
because the component splits it into individual letters for the animation.
