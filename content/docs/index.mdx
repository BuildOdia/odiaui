## Installation

Add the odiaui registry to your project:

```bash
npx shadcn@latest registry add @odiaui=__SITE_URL__/r/{name}.json
```

Then install any component:

```bash
npx shadcn@latest add @odiaui/button
```

## What is this?

odiaui is a custom component registry built on the [shadcn registry protocol](https://ui.shadcn.com/docs/registry). You can install any component with the shadcn CLI — they'll be copied into your project as source code that you own and can customize.
