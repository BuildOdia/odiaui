---
title: Installation
description: How to install odiaui components in your project.
---

## Prerequisites

You need a project with [shadcn/ui](https://ui.shadcn.com) already configured. If you haven't set up shadcn yet:

```bash
npx shadcn@latest init
```

## Add the Registry

### Using Namespace (Recommended)

```bash
npx shadcn@latest registry add @odiaui=__SITE_URL__/r/{name}.json
```

Then install components by namespace:

```bash
npx shadcn@latest add @odiaui/button
```

### Using URL

You can also install directly by URL:

```bash
npx shadcn@latest add __SITE_URL__/r/button.json
```

## Browse Components

Use the `list` command to see all available components:

```bash
npx shadcn@latest list @odiaui
```
